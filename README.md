# SimpleInventory

Planning and repository bootstrap for an ASP.NET Core inventory and order management API.

## Current Status

This repository currently contains bootstrap documentation and agreed implementation notes. Application code has not been started yet.

## Published Documentation

- [`NOTES.md`](./NOTES.md) - agreed architecture, assumptions, and trade-offs

## Planned Solution

The implementation is planned as:

- ASP.NET Core Web API with controllers
- SQLite persistence
- CQRS with MediatR-style handlers
- FluentValidation and ProblemDetails
- Scalar with OpenAPI 3.1
- Unit and integration tests

## Repository Bootstrap

The repository has been prepared with:

- initial documentation
- a .NET-oriented `.gitignore`
- local planning artifacts kept out of source control
